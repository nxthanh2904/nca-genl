# Ôn tập NVIDIA NCA-GENL

Bộ tài liệu tiếng Việt giúp bạn học về **AI tạo sinh và mô hình ngôn ngữ lớn (LLM)** để ôn chứng chỉ **NVIDIA Certified Associate – Generative AI and LLMs (NCA-GENL)**.

Phù hợp với lập trình viên và người học AI muốn hiểu khái niệm qua giải thích, bảng so sánh, sơ đồ và ví dụ code.

## Bắt đầu học

1. Đọc các module bên dưới theo thứ tự để xây dựng nền tảng; nếu đã có kiến thức, chọn chủ đề cần ôn.
2. Làm câu hỏi trong [Cẩm nang ôn thi](./NCA_GENL_Exam_Guide_and_Tips.md), ghi lại lỗi sai và đọc lại phần chưa hiểu.
3. Mở [index.html](./index.html) bằng trình duyệt để học và thi thử tương tác. Cần Internet để tải thư viện và font hiển thị.
